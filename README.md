# Título VI — Código de Ética Profesional

Presentación web estática sobre el Título VI, artículo 21 (incisos a–h), del Código de Ética Profesional del Colegio de Ingenieros de Guatemala.

## Estructura

- `index.html`: estructura y contenido de las diapositivas.
- `css/styles.css`: diseño responsivo y animaciones.
- `js/presentation.js`: navegación, pantalla completa y notas del expositor.

## Uso local

Abre `index.html` en tu navegador. No requiere instalación ni dependencias externas.

- Flechas izquierda/derecha: cambiar de diapositiva.
- N: mostrar u ocultar notas.
- F: entrar o salir de pantalla completa.
- Botones inferiores: navegación y controles.

## Publicar en GitHub Pages

1. Sube la carpeta al repositorio (con `index.html` en la raíz del repositorio).
2. Ve a **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama principal y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.

Las imágenes de la presentación son ilustraciones mediante emojis y formas CSS; no requieren conexión ni servicios externos.
